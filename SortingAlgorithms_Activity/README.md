
Sorting Algorithms Activity

Kini nga program gihimo gamit ang Java para ipakita kung giunsa pag-sort ang mga numbers gikan sa pinakagamay hangtod sa pinakadako. Gigamit nako ani ang tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort.

Kani pud siya kay naay 10 ka unsorted numbers. Tagsa-tagsa nga copy sa original array ang gigamit sa kada algorithm aron patas ang ilang pag-sort ug dili mausab ang original data.

Explanation of Each Sorting Algorithm

1. Bubble Sort
Ang Bubble Sort siya ang ga compare sa duha ka magtapad nga numbers. Kung mas dako ang naa sa wala kaysa naa sa tuo, iyang ibaylo ang ilang position. Balik-balikon dayon niya hangtod ma-arrange ang tanang numbers.

2. Selection Sort
Ang Selection Sort mangita siya una sa pinakagamay nga number sa array. Ibutang dayon siya sa pinaka una nga position gamit ang pag-swap. Ipadayon dayon siya siya sa sunod nga mga position hangtod ma-sort ang tibuok array.

3. Insertion Sort
Ang Insertion Sort, ingon pa ni Maam nga mura shag parehas sa paghan-ay og playing cards. Kuhaon niya ang isa ka number ug ibutang sa sakto nga position bisan paman sa mga numbers nga nauna nang na-arrange.

Differences Between the Three Algorithms

Lahi-lahi ang pamaagi sa tulo ka algorithms. Ang Bubble Sort mag compare sa magtapad nga numbers, ang Selection Sort mangita sa pinakagamay nga value, samtang ang Insertion Sort magbalhin sa mga number aron maipasulod ang isa ka value sa sakto nga lugar.

Reflection Questions

1. How does each sorting algorithm arrange numbers? How are their processes different?

Ang Bubble Sort magkumpara sa magtapad nga numbers ug mag-swap kung kinahanglan. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang niya sa unahan. Ang Insertion Sort magkuha og isa ka number ug mangita sa sakto nga lugar ato. Pareho silang nag-arrange sa numbers, pero lahi ang ilang proseso.

2. Which algorithm was easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton. Sayon ra masabtan ang proseso kay magkumpara lang kini sa duha ka magtapad nga numbers ug mag-ilis sa ilang position kung dili sila sakto ang pagkahan-ay.

3. Which algorithm performs better when the data is already sorted? Why?

Ang Bubble Sort ug Insertion Sort kay mas paspas kung sorted na daan ang data. Ang Bubble Sort inig makabantay nga walay kinahanglan i-swap mohunong dayon. Ang Insertion Sort dili na kaayo kinahanglan magbalhin-balhin sa mga numbers. Pareho sila nga naay O(n) best-case time complexity.

4. How does adding more numbers affect the performance of sorting algorithms?

Kung mudaghan ang mga numbers, mas daghan pud ang trabaho nga buhaton sa sorting algorithms. Rason nga mas dugay ang ilang pag-sort labi na kung daghan ang kinahanglan ikumpara o ibalhin. Mao nga importante ang pagpili sa angay nga algorithm depende sa kadaghan ug kahimtang sa data.

5. Why should future programmers understand multiple sorting algorithms?

Importante nga makasabot ang future programmers sa lain-laing sorting algorithms kay dili parehas ang ilang performance ug pamaagi. Pinaagi niini, makapili sila og algorithm nga mas angay sa ilang program ug sa klase sa data nga ilang gi-process.
